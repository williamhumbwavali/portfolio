* Route and schedule management
* Subscription-based rides
* Administrative dashboard
* Web and mobile applications

**Stack:** Next.js · NestJS · React Native · TypeScript · MySQL · TypeORM · Docker

### Bando CMS

Open-source, self-hosted CMS designed to make content management easier for web applications.

* Content management
* Admin Studio
* REST API
* PostgreSQL
* TypeScript-first architecture

**Stack:** TypeScript · Node.js · Express.js · PostgreSQL · React · Next.js · Docker

### Lithe PHP

Open-source PHP framework created from scratch, inspired by the simplicity of Express.js.

* Routing
* Middleware
* ORM support
* CLI tools
* Modular architecture
* Composer distribution

**Stack:** PHP · Composer · PSR · Symfony Console · PHPUnit

### Bad Vibes Forever

Music platform focused on independent artists, built from frontend to backend.

* Artist profiles
* Albums and playlists
* Music uploads
* Streaming
* Downloads
* Likes and listening history

**Stack:** Next.js · React · TypeScript · NestJS · PostgreSQL · TypeORM · Cloudflare R2

E-commerce platform created, developed and operated for the Angolan market.

**Stack:** PHP · Lithe · Eloquent · Blade · MySQL
